- **HTML5**：语义化标签（`header` / `nav` / `main` / `section` / `article` / `footer`）、`aria-*` 无障碍属性

### 响应式与无障碍

- **三档布局**：>960px 三列；≤960px 两列 + 收起导航菜单；≤640px 单列。缩放窗口无横向溢出。
- **无障碍**：跳转链接、`aria-selected` / `aria-expanded` 状态同步、`tabindex` 管理、`:focus-visible` 焦点样式。
- **动效克制**：尊重系统"减少动态效果"设置（`prefers-reduced-motion`），另提供打印样式。

## 六、本人实现的特色内容

1. **方向对比用 Tab 呈现，而不是平铺**：升学与就业两条路各自写清原因、短期与中期目标，第三个 Tab 专门写"我的比较与结论"（当前倾向升学），把思考过程展示出来而不只给结论。
2. **技能条与滚动绑定**：技能条不是静态的，滚动到该区域时才从 0 增长到设定值；用 `IntersectionObserver` + CSS 过渡实现，不监听 `scroll` 事件、不触发重排。
3. **主题切换"一处改、全站变"**：所有颜色写成 CSS 变量，深色主题只重新赋值同一批变量，JS 只改 `<html>` 上的一个属性，无需逐个元素改样式。
4. **手写折叠面板**：不用 `<details>`（它的高度变化无法做过渡动画），而是用 JS 读取内容实际高度驱动 `max-height`，展开动画结束后置为 `none`，避免长文本被固定高度裁掉。
5. **三种版式混排**：卡片网格（关于我）+ 时间轴（行动计划）+ 手风琴（学习目标），避免通篇卡片堆叠，重要信息更好定位。
6. **页面细节**：头像用 `img` + `object-fit: cover` 裁成圆形并加渐变描边；导航高亮随滚动切换；页脚年份自动更新。

## 八、附录：主要实现思路（考核要求"能解释自己的主要代码"）

1. **主题切换怎么做到一处切换、全站换色？**
   颜色全部写成 CSS 变量（`--bg`、`--text`、`--accent` 等）定义在 `:root`，深色主题在
   `[data-theme="dark"]` 里重新赋值同一批变量；JS 只改 `<html>` 的一个属性，所有引用这些
   变量的样式自动更新，不需要逐个元素改。
2. **`IntersectionObserver` 和 `scroll` 事件有什么区别？**
   它在元素进入 / 离开视口时由浏览器异步回调，不必在滚动事件里反复调用
   `getBoundingClientRect()`（那会强制重排）。本页用它做导航高亮、内容渐入、技能条增长；
   `rootMargin: '-45% 0px -50% 0px'` 把判定区域收窄成屏幕中部一条线，避免相邻区块来回跳。
3. **折叠面板为什么不用 `<details>`？**
   `<details>` 的高度变化无法做过渡。这里用 JS 读取 `scrollHeight` 实测高度设置
   `max-height` 触发 CSS 过渡；展开结束后改为 `none`，内容再变长也不会被裁剪。
   从 `none` 收起时先锁定当前高度并强制重排，否则浏览器算不出起始高度、动画会跳变。
4. **`localStorage` 存了什么？**
   只存一个键 `homepage-theme`（`light` / `dark`）；没存过就读取系统的
   `prefers-color-scheme` 偏好。
5. **响应式是怎么实现的？**
   主布局用 Grid（`.grid-3` / `.grid-2`）和 Flex（页头、按钮组），在 960px / 640px 两个
   断点降列、收起导航、缩小间距；标题字号用 `clamp()` 自适应，避免小屏文字过大。
6. **为什么 HTML 里没有内联样式和 `onclick`？**
   结构、样式、行为分离：样式集中在 `style.css`，事件统一在 `main.js` 里用
   `addEventListener` 绑定，便于维护，也符合代码规范要求。
